Introduction

Kotlin is a modern, statically typed programming language used by developers worldwide. It is designed to be completely interoperable with Java, concise, and safe.

Kotlin can be used for various types of development, including:

  • Android mobile development
  • Server-side applications
  • Multiplatform projects

To print text to the console, you use the standard library function:

println("Hello, World!")
Basic Types

In Kotlin, everything is an object in the sense that you can call member functions and properties on any variable.

Some built-in types representing numbers include:

  • Int for integer numbers
  • Double for 64-bit floating-point numbers

Unlike Java, numbers do not undergo implicit widening conversions; for example, an Int cannot be assigned directly to a Double without explicit conversion.

Variables

Kotlin uses two different keywords to declare variables depending on whether the value is mutable or read-only.

Use the val keyword for a read-only variable whose value cannot be reassigned once set:

val name = "Kotlin"

Use the var keyword for a mutable variable whose value can change later during program execution:

var score = 0
Conditional Expressions

In Kotlin, if is an expression, meaning it returns a value. Therefore, there is no ternary operator because an ordinary if works perfectly in this role.

Here is an example of using a conditional expression to assign a value:

val max = if (a > b) a else b

You can also use when as a more robust replacement for the traditional switch statement.

Functions

Kotlin functions are declared using the fun keyword followed by the function name, arguments, and an optional return type.

Here is a basic function definition that takes two parameters and returns an integer:

fun sum(a: Int, b: Int): Int { return a + b }

Functions with a single expression body can also drop the curly braces and specify the body after an equality sign.
